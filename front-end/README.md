## 📌 About

**Sajilo Aawas - Frontend** is the client-side application for the Sajilo Aawas system. It allows users to:

✔ Browse listings
✔ Search and filter
✔ Create and manage user accounts
✔ View details & more

This repository contains only the **frontend code**.

---

## 🚀 Features

✔ Responsive user interface
✔ Routing with React Router
✔ Connects with backend API
✔ User authentication UI
✔ Clean & scalable codebase

## ⚙️ Prerequisites

Before you install, make sure you have the following installed:

✔ **Node.js** (>= v14)
✔ **npm** (comes with Node.js)
✔ Git (for version control)

You can check your versions:

```bash
node -v
npm -v
```

---

## 🛠 Installation

Clone the repository:

```bash
git clone https://github.com/thapasujan/sajilo_aawas_frontend.git
```

Change directory:

```bash
cd sajilo_aawas_frontend
```

Install dependencies:

```bash
npm install
```

> 📝 This will install all required node modules listed in `package.json`.

---

## ▶️ Running the App

To start the development server:

```bash
npm start
```

This starts the app at:

👉 [http://localhost:3000](http://localhost:3000)

You should see the app running successfully in your browser.

---

## 📦 Build for Production

To create a production-ready optimized build:

```bash
npm run build
```

This generates a `build/` folder with the final optimized bundle.

---

## 🔌 Using a Backend API

This frontend is meant to work with a backend API.
Before running, make sure you have your backend running and configured.

You may need to set API URLs in:

* `.env` file (if configured)
* Config file where backend endpoints are defined

Example `.env`:

```bash
REACT_APP_API_URL=https://api.yourbackend.com
```

Make sure to restart the server after updating `.env`.
